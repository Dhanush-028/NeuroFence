# NeuroFence

## Overview
NeuroFence is a cybersecurity project designed to detect suspicious behaviour and potential LLM weight poisoning attacks. It helps analyse models and generate security reports for safer AI deployment.

## Features
- LLM weight poisoning detection
- Anomaly detection
- Report generation
- User-friendly desktop interface

## Requirements
- Python 3.10 or above
- Required Python packages listed in `requirements.txt`

## How to Run
1. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python desktop_ui.py
   ```
